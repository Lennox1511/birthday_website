# R1 版本记录

- 版本：R1.1.0
- 更新日期：2026-10-17
- 页面入口：`index.html`
- 画面比例：3:4 竖版像素风场景

## 当前功能

- 使用 Fig.1.1 作为海滩背景。
- 叠加陵水岛屿地图、日历木框和两层日历内容。
- 灵珠匀速从云层降落，点击可在灵珠与魔丸之间反复切换。
- 点击漂流瓶后，神秘来信会从漂流瓶位置展开；信件出现后才允许拖动日历右下角。
- 从 Fig.3.2 日历右下角开始向外拖动，日历内容会掉落并淡出。
- Fig.3.5 位于 Fig.3.2 下层，Fig.3.2 掉落后可显示下层日历。
- Fig.5.1 和 Fig.5.2 位于右下角，点击任意一棵会让两棵同步摇晃。

## 封装内容

- `index.html`：页面结构
- `style.css`：像素风布局和动画样式
- `scene.js`：灵珠切换、漂流瓶信件、日历拖拽和棕榈树交互逻辑
- `素材/`：本版本使用和保留的本地图片素材

预览地址：`http://localhost:5173/R1/`
