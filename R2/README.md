# 海岛奇缘 · 生日网页 R2

版本：R2.0.1  ·  整理日期：2026-10-18

本版本是 `yybirth` 当前制作成果的独立快照，保留 3:4 竖版像素风画面、白天与夜晚两页场景、生日剧情、烟花和音频交互。

## 打开网页

1. 如果收到的是 `R2.zip`，先完整解压。
2. 双击本目录的 `index.html`，使用较新版本的 Chrome、Edge 或 Safari 打开。
3. 保持 HTML、CSS、JavaScript 和 `素材/` 的相对位置，分享时发送完整目录或压缩包。

网页无需安装依赖或执行构建。图片、音乐与音效均随包保存；CSS 中的 Google Fonts 字体会在联网时尝试加载，离线时使用系统备用字体，页面交互不依赖该字体服务。

如需通过本地服务器预览，可在本目录运行 `python -m http.server 5173`，再访问 `http://localhost:5173/`；这一步是可选的。也可将完整目录上传到静态网站托管服务。

## 体验顺序

1. 第一页可点击灵珠切换外观，点击棕榈树让树叶摇晃并发出沙沙声。
2. 打开漂流瓶，阅读并收起来信，再从十月日历右下角向外拖动，进入夜晚庆典。
3. 第二页点击烟花盒，可反复发射烟花：曲线轨迹、自然拖尾、26 种柔和图案与随机大小，每发均有发射及绽放音效。
4. 第二页完整摇晃棕榈树 6 次，等待彩蛋落地后点击彩蛋，选择“吃掉”。
5. 点击渔夫上方的感叹号，查看项链并选择“戴上”。小黑猫随后走出来，伴随两声喵叫。
6. 等小黑猫坐好后点击它，出现生日祝福，女孩与少年切换为最终形象，并自动发射蛋糕烟花。

背景音乐在首次有效点击后开始：白天为《晴日海风》，夜晚为《星灯庆典》。左上角“音乐”按钮控制背景音乐；树叶、猫叫和烟花音效随各自交互播放。浏览器可能要求用户先操作页面才允许播放声音。

两页背景音乐已降低响度；猫叫、树叶和烟花音效播放时，音乐会自动减弱，音效结束后平滑恢复。iPhone / iPad 使用较轻的音乐文件，并在音效期间暂时让出背景音乐。

刷新网页会重新开始剧情。网页会记住背景音乐的开关偏好。

## 文件组成

| 文件 | 内容 |
|---|---|
| `index.html` | 两页场景、剧情弹窗与本地音频入口 |
| `style.css` | 像素风布局、响应式尺寸及动画 |
| `scene.js` | 翻页、棕榈树、彩蛋、项链、小猫与生日剧情 |
| `scene-music.js` | 场景背景音乐、切换与开关 |
| `firework-shapes.js` | 26 种烟花图案 |
| `island-fireworks.js` | 烟花盒、曲线路径与粒子绽放 |
| `birthday-fireworks.js` | 自动生日蛋糕烟花 |
| `firework-audio.js` | 发射、绽放与星火余响的声音合成 |
| `素材/` | 本地图片、音频及音频来源说明 |
| `版本记录.md` | R2 的功能与版本范围 |
| `文件清单.json` | 相对路径、文件大小与 SHA-256 校验值 |

本包不包含开发缓存、浏览器测试截图、下载中间文件或音频处理脚本。音频来源与说明保存在 `素材/`，其中猫叫素材采用 CC0 1.0 许可；两首背景音乐为本项目原创合成编曲。其余图片沿用开发目录提供的素材，本次整理不变更其来源或许可。
