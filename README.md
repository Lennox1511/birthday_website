# birthday_website_making

本项目收录像素风生日互动网页，包括“海岛奇缘”的开发目录与两个版本快照，以及独立的河畔夜景网页“A Little Shiny Night”。本说明用于了解目录结构、文件职责、预览方法和互动流程。

页面使用原生 HTML、CSS 和 JavaScript 编写，无需安装 npm 依赖或执行构建。海岛场景使用图片叠层与动画，河畔场景使用 Canvas 2D 绘制。

根目录没有统一的 `index.html`，预览时需要选择具体子目录。

| 目录或文件 | 用途与范围 |
| --- | --- |
| `yybirth/` | 海岛场景的继续开发入口，包含白天、夜晚、生日剧情、烟花与音频模块。 |
| `R1/` | 早期快照，版本记录标注为 R1.1.0（2026-10-17），包含灵珠、漂流瓶、日历拖拽和棕榈树交互。 |
| `R2/` | 完整剧情快照，版本记录标注为 R2.0.1（2026-10-18），额外提供 README、版本记录和文件校验清单。 |
| `R1.zip`、`R2.zip` | 对应版本的分发压缩包；后续修改目录内容不会自动更新压缩包。 |
| `reverse-site/` | 独立的河畔夜景实现，使用 JavaScript ES 模块组织代码。 |

## 本地预览

推荐在本 README 所在目录启动静态服务器。安装 Python 后运行：

```powershell
cd D:\website_making\birthday_website
python -m http.server 5173
```

然后在浏览器中打开所需页面：

| 页面 | 本地地址 |
| --- | --- |
| 海岛开发版 | <http://localhost:5173/yybirth/> |
| 海岛 R1 | <http://localhost:5173/R1/> |
| 海岛 R2 | <http://localhost:5173/R2/> |
| 河畔夜景 | <http://localhost:5173/reverse-site/> |

服务器运行期间保持终端开启，结束时按 `Ctrl+C`。上述命令只用于静态文件预览，不需要后端服务。

海岛版本也可直接双击对应目录中的 `index.html` 打开；`reverse-site/` 使用 ES 模块，应通过 HTTP 静态服务器访问。建议使用较新版本的 Chrome、Edge 或 Safari。

## 海岛奇缘：文件与互动

### 主要文件

以下职责对应 `yybirth/`，R2 保留相同的模块划分；R1 仅包含早期页面的 HTML、CSS、`scene.js` 和素材。

| 文件 | 职责 |
| --- | --- |
| `index.html` | 白天与夜晚场景元素、剧情弹窗、音频入口及脚本加载顺序。 |
| `style.css` | 3:4 竖版像素风布局、响应式适配、人物与物件动画。 |
| `scene.js` | 灵珠切换、信件、日历拖拽、翻页、棕榈树、彩蛋、项链、小猫和生日剧情。 |
| `scene-music.js` | 白天与夜晚背景音乐、音乐开关、偏好保存及音效期间的音乐减弱。 |
| `firework-shapes.js` | 26 种烟花图案的数据与生成逻辑。 |
| `island-fireworks.js` | 烟花盒交互、飞行轨迹、粒子绽放与拖尾。 |
| `birthday-fireworks.js` | 生日结尾自动触发的蛋糕烟花。 |
| `firework-audio.js` | 烟花发射、绽放与余响的声音合成。 |
| `素材/` | 场景背景、日历、人物、道具图片，以及 OGG/WAV 音乐与音效。部分图片为预留素材。 |
| `output/audio/` | 猫叫音频的处理脚本、中间文件和统计，网页运行无需此目录。 |

`R2/README.md` 提供该版本的详细说明；`R1/版本记录.md` 与 `R2/版本记录.md` 记录各自的功能范围。`R2/文件清单.json` 保存相对路径、文件大小与 SHA-256 校验值，可用于核对快照文件；修改 R2 后需同步更新清单。

### 完整剧情操作（yybirth / R2）

1. 在白天场景点击灵珠，可切换灵珠与魔丸；点击棕榈树可使树叶摇晃。
2. 点击漂流瓶阅读来信，收起来信后，从十月日历右下角向外拖动，进入夜晚庆典。
3. 夜晚点击烟花盒可重复发射烟花。
4. 在夜晚累计完成 6 次棕榈树摇晃，等彩蛋落地后点击彩蛋，选择“吃掉”。
5. 点击渔夫上方的感叹号查看项链，选择“戴上”，等待小黑猫走出并坐下。
6. 点击坐好的小黑猫，显示生日祝福、切换人物最终形象，并自动发射蛋糕烟花。

背景音乐在首次有效操作后开始：白天为《晴日海风》，夜晚为《星灯庆典》。左上角按钮控制背景音乐；树叶、猫叫和烟花音效随交互触发，播放时背景音乐会减弱。iPhone / iPad 的音效期间采用暂停背景音乐再恢复的处理。刷新页面会重新开始剧情，背景音乐开关偏好会被保存。

## A Little Shiny Night：文件与互动

河畔页面以 360 × 640 的 Canvas 为绘制坐标，展示人物、蛋糕、狼、留声机和夜景。

| 文件 | 职责 |
| --- | --- |
| `index.html` | Canvas、开始按钮、蛋糕交互入口与生日祝福对话框。 |
| `style.css` | 页面尺寸适配、开始界面和对话框样式。 |
| `game.js` | 加载图片、启动动画循环，组合场景、光照、人物、音乐与输入模块。 |
| `state.js` | 开始与游玩阶段、蜡烛点亮、人物状态和祝福触发规则。 |
| `input.js` | 鼠标与触摸的 Pointer Events、拖动光照、蛋糕和留声机操作及部分键盘交互。 |
| `dialog.js` | “生日快乐，我的异色”的逐字显示与对话框状态。 |
| `music.js` | 钢琴音频播放、重播、错误状态与唱片转动角度。 |
| `motion.js` | 人物姿态、眨眼、草地等细微动画。 |
| `night.js` | 音乐结束后的流星时序、绘制与微风辅助函数。 |
| `reflections.js` | 局部光照下的倒影效果。 |
| `secrets.js` | 人物微光联动、小花、隐藏光点与狼的苏醒动画。 |
| `assets/` | 背景、人物不同姿态、蛋糕、毯子、狼与留声机图片。 |

操作方式：

1. 图片加载完成后点击 `PRESS START`。
2. 按住并移动鼠标或手指，使用暖色光照探索场景。
3. 在蛋糕区域松开可点亮蜡烛，人物随之切换姿态，并尝试播放音乐。
4. 点亮后再次短按蛋糕可显示生日祝福；点击对话框关闭。
5. 按住探索人物、狼和小花附近，可触发局部隐藏效果。音乐结束或播放失败后，短按留声机可尝试重播。

**当前素材缺失：** `music.js` 引用了 `assets/birthday-piano.mp3`，但当前 `reverse-site/assets/` 中没有该文件。音乐播放会失败；代码允许基本交互继续运行，但依赖音乐正常结束事件的流星流程也无法按设计触发。如需完整体验，应补齐该路径对应的音频。

## 修改、分享与部署

- 继续开发海岛场景时，优先修改 `yybirth/`；如需发布新快照，另行整理版本目录、版本记录、校验清单和压缩包。
- 修改祝福文字时，海岛页面可查看 `yybirth/index.html` 的 `birthday-message`；河畔页面可查看 `reverse-site/dialog.js` 的 `BLESSING`，并同步调整 `index.html` 中对应的无障碍描述。
- 替换图片、音乐或音效后，需同步更新 HTML、CSS 或 JavaScript 中引用的路径；保留文件名中的中文和空格。
- 分享海岛页面时，应发送完整目录或压缩包；部署时保留 HTML、脚本、样式和素材的相对位置。
- 可将所需子目录的完整内容上传至静态网站托管服务。若部署整个项目，访问地址需包含对应子目录，或自行添加根目录导航页。

## 素材来源与现有说明的边界

海岛音频来源见 [小黑猫音效来源](yybirth/素材/小黑猫音效来源.md) 和 [原创循环音乐说明](yybirth/素材/原创循环音乐说明.md)：猫叫来源文件标注为 skymary 的 Freesound 录音，采用 CC0 1.0；两首背景音乐在随附说明中记录为本项目原创合成编曲。图片及其他素材未在根目录提供统一授权说明，具体使用范围需结合各素材来源确认。

当前目录未包含原创音乐说明中提及的 `output/audio/generate-island-music.py`；已导出的音乐文件仍保留在素材目录。猫叫处理脚本位于 `yybirth/output/audio/prepare_cat_meow.py`，其依赖与来源见随附说明；网页预览无需运行这些处理脚本。

海岛 CSS 会尝试从 Google Fonts 加载字体，离线时使用备用字体。浏览器通常要求用户先操作页面才允许音频播放。R2 版本记录中的 Chromium 流程验证属于历史记录，其中也注明未进行实机 Safari 听感验收；本 README 根据现有文件与代码整理，不代表本次重新完成浏览器或移动设备测试。
